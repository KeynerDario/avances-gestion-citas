# DashboardLayout Component

El `DashboardLayout` es un componente de diseño reutilizable que proporciona una navegación consistente, cabecera y área de contenido para todos los paneles de control de la aplicación.

## Características principales

- **Navegación lateral colapsable**: 256px expandida, 64px colapsada con funcionalidad de mouse-over
- **Cabecera estandarizada**: Título + navegación de migas de pan + botones de acción
- **Área de contenido flexible**: Para el contenido del dashboard con estados de carga y vacío
- **Responsivo para móviles**: Menú lateral deslizante, cabecera adaptada para móviles
- **Mínimos de área táctil de 44px**
- **Accesible**: Etiquetas ARIA, navegación por teclado, soporte para lectores de pantalla
- **Visible según rol**: Mostrar elementos de navegación según el rol del usuario
- **Personalizable**: Acepta props para título, migas de pan, acciones y más

## Instalación

```bash
npm install react lucide-react
```

## Importación

```jsx
import { DashboardLayout } from './shared/components/DashboardLayout';
```

## Props

| Prop | Tipo | Requerido | Descripción |
|------|------|----------|-------------|
| `title` | string | Sí | Título del dashboard que aparece en la cabecera |
| `breadcrumbs` | string[] | No (predeterminado: []) | Array de elementos de navegación de migas de pan |
| `actions` | Array | No (predeterminado: []) | Array de objetos de acción con `label`, `onClick`, `icon`, etc. |
| `userRole` | string | Sí | Rol del usuario para filtrar elementos de navegación (SUPERADMIN, COORDINACION, PROFESIONAL, APRENDIZ) |
| `loading` | boolean | No (predeterminado: false) | Muestra estado de carga en el área de contenido |
| `empty` | boolean | No (predeterminado: false) | Muestra estado vacío cuando no hay contenido |
| `children` | React.ReactNode | Sí | Contenido del dashboard que se renderiza en el área principal |

## Ejemplo Básico

```jsx
import { DashboardLayout } from './shared/components/DashboardLayout';

export function MisDashboard() {
  const actions = [
    {
      label: "Actualizar",
      onClick: () => console.log("Actualizando..."),
      icon: <RefreshCw size={16} />,
    },
    {
      label: "Exportar",
      onClick: () => console.log("Exportando..."),
      icon: <Download size={16} />,
    },
  ];

  return (
    <DashboardLayout
      title="Mi Dashboard"
      breadcrumbs={["Dashboard", "Inicio"]}
      actions={actions}
      userRole="PROFESIONAL"
      loading={false}
      empty={false}
    >
      <div className="content">
        <h2>Contenido del Dashboard</h2>
        <p>Aquí va el contenido principal</p>
      </div>
    </DashboardLayout>
  );
}
```

## Estructura de Navegación

El componente incluye un menú lateral con navegación organizada por roles. Los elementos de navegación están filtrados según el rol del usuario:

- **SUPERADMIN**: Todos los elementos
- **COORDINACION**: Inicio, Mis Citas, Agenda, Profesionales, Dependencias, Reportes
- **PROFESIONAL**: Inicio, Mis Citas, Agenda
- **APRENDIZ**: Inicio, Mis Citas

### Elementos de Navegación

| Elemento | Icono | Roles Permitidos |
|---------|-------|-----------------|
| Inicio | 🏠 | Todos |
| Mis Citas | 📅 | Aprendiz, Profesional, Coordinación |
| Agenda | 📆 | Profesional, Coordinación |
| Profesionales | 👥 | Coordinación, Superadmin |
| Usuarios | 👤 | Superadmin |
| Dependencias | 🏢 | Superadmin, Coordinación |
| Reportes | 📊 | Coordinación, Superadmin |

## Personalización

### Colores según rol

El componente incluye colores específicos según el rol del usuario:

- **Superadmin**: `var(--sena-green)`
- **Coordinación**: `var(--color-info)` (azul)
- **Profesional**: `var(--color-purple)`
- **Aprendiz**: `var(--gray-600)`

### Iconos de rol

El componente incluye iconos específicos según el rol:

- **Superadmin**: Shield (icono de protección)
- **Coordinación**: Building2 (icono de edificio)
- **Profesional**: Users (icono de usuarios)
- **Aprendiz**: User (icono de usuario)

### Características del estado de carga

```jsx
<DashboardLayout
  ...
  loading={isLoading}
>
  {/* El contenido se ocultará mientras loading sea true */}
  <div className="content">Tu contenido aquí</div>
</DashboardLayout>
```

### Características del estado vacío

```jsx
<DashboardLayout
  ...
  empty={data.length === 0}
>
  {/* El estado vacío se mostrará cuando empty sea true */}
  <div className="content">Tu contenido aquí</div>
</DashboardLayout>
```

## Estilos y Personalización

El componente utiliza CSS custom properties desde `variables.css`:

### Variables personalizadas

- `--sidebar-width-expanded`: Ancho del sidebar expandido (256px)
- `--sidebar-width-collapsed`: Ancho del sidebar colapsado (64px)
- `--sidebar-mobile-width`: Ancho del sidebar en móvil (90% del ancho de pantalla)

### Modo oscuro

El componente es compatible con el modo oscuro a través del sistema de tema global:

```css
@media (prefers-color-scheme: dark) {
  .dashboard-layout {
    background: var(--bg-primary);
  }
  .dashboard-header {
    background: var(--bg-secondary);
  }
  .dashboard-sidebar {
    background: var(--bg-secondary);
  }
}
```

## Accesibilidad

### Etiquetas ARIA

El componente incluye:

- `aria-label="Navegación principal"` en el elemento de navegación
- `role="navigation"` en el elemento nav
- `aria-current="page"` en el elemento de navegación activo
- `aria-expanded` y `aria-controls` en el botón del sidebar para móviles

### Navegación por teclado

- **Tab**: Navegación por teclado a través de elementos interactivos
- **Enter/Space**: Activación de elementos del menú y botones
- **Flechas**: Navegación en el menú lateral (horizontal en móvil, vertical en desktop)
- **Escape**: Cerrar menú móvil y dialogs

### Soporte para lectores de pantalla

- Todos los textos alternativos para iconos SVG
- Estados de carga y vacío con `aria-live="polite"`
- Anchos mínimos de área táctil de 44px en móvil
- Etiquetas de título descriptivas

## Manejo de errores

El componente incluye estado de carga y vacío:

```jsx
<DashboardLayout
  loading={isLoading}
  empty={!data && !loading}
>
  {data ? content : null}
</DashboardLayout>
```

El estado de carga muestra un spinner con aria-live="polite" para lectores de pantalla.
El estado vacío muestra un icono y mensaje descriptivo.

## Guía de estilos

### Requisitos CSS

- **Framework**: No se basa en ningún framework CSS específico
- **Variables personalizadas**: Utiliza todas las variables del sistema de diseño
- **Móvil primero**: Las actualizaciones de estilos se hacen desde dispositivos móviles hacia arriba
- **Modo oscuro**: Es compatible con el tema oscuro del sistema

### Responsive Design

- **Desktop**: Sidebar fijo a la izquierda, contenido principal con margen izquierdo
- **Tablet (≤768px)**: Sidebar oculto por defecto, botón para abrir, deslizamiento desde la izquierda
- **Móvil (≤768px)**: Sidebar deslizante, overlay de fondo, scroll interno para navegación larga

### Transiciones

- **Sidebar**: Transición suave entre estados expandido/colapsado
- **Móvil**: Animación de deslizamiento para menú
- **Contenido**: Transiciones de opacidad para estados de carga y vacío
